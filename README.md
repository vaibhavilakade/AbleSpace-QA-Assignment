# AbleSpace QA Assignment

## 1. Project Overview

This repository contains the QA testing documentation and evidence for the AbleSpace application.

## 2. Objective

The objective of this assignment is to validate the application's functionality, usability, validation, and overall user experience.

## 3. Application Under Test

**Application:** AbleSpace  
**Environment:** Staging  
**Testing Type:** Manual Testing

## 4. Testing Scope

The following areas were covered:

- Functional Testing
- Negative Testing
- Validation Testing
- UI/Usability Testing
- Browser Compatibility Testing
- Responsive Testing
